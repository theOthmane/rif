# FAQ — starter questions (owner fills the answers)

The FAQ page template splits the page content on **Heading 3** elements:

- each Heading 3 is one question,
- the paragraphs under it are its answer,
- content before the first Heading 3 becomes the intro,
- a page with no Heading 3 renders as a normal rich-text page.

To use this file: open **Pages** in the Shopify admin, create the FAQ page,
assign it the `page.faq` template, then paste the questions below as Heading 3
blocks and write the answer under each one.

No answers are provided here on purpose: delivery times, warranty terms and
returns are commitments the owner must write, not the theme.
